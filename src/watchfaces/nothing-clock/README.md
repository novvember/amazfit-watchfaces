# Nothing Clock Watchface

Watchface for round Zepp OS watches.

![Nothing Clock on Amazfit GTR Mini](./demo-gtr-mini.png)

## Description

A minimal analog watchface. Shows the date and weekday on the right, with step count, sleep duration, and battery level at the bottom. Choose an accent color in the watchface settings. Includes a simplified AOD.

Inspired by a home screen widget on the Nothing Phone.

**Languages:** English, Russian
