# Nothing Clock 2 Watchface

Watchface for round Zepp OS watches.

![Nothing Clock 2 on Amazfit GTR Mini](./demo-gtr-mini.png)

## Description

A digital watchface with large time digits and compact rows of everyday information. Shows time (with a separate seconds display), date, weather, step count, distance walked, battery level, and sleep duration. Includes AOD support.

Inspired by Nothing Phone widgets.

**Languages:** English, Russian
