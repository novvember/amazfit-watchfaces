# The Unlikeables Watchface
Watchface for round ZeppOS watch.

![demo](./demo-gtr-mini.png)

## Description
A watch face where every digit has its own personality. Shows time, date, and steps. Configure background color in settings. AOD supported. Original design by Shuka Bureau for Yandex TV Station.

**Language:** English, Russian
